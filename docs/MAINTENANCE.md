# 后续制作与恢复

1. 先读PIPELINE_STATE、来源缺口与远端回执；核原件和规范哈希。
2. 补印刷73、92页时，登记新来源身份、版次和邻页接续；不覆盖旧原件，不把另一教材当同版补页。
3. 得到阶段0范围确认后，按五类角色提取。用户已授权蒸馏和上传，不再重复询问同一事项。尚未授权的全局安装、合并、标签和GitHub Release保持分开。
4. 从tasks.json追踪任务→来源→候选→四分流→实际能力/参考/待核，不能从通过项反推任务分母。
5. 每个active算法补正常新输入与边界输入，固定预期并保存真实输出。一般结论、有限枚举和模型增益分别举证。
6. 将能力维护在单一Bundle；从事实源编译single，不手改dist产物。
7. 发布前运行`python scripts/freeze_public.py`，核白名单与哈希；任何输入变更重新冻结。以相同Git对象格式核远端文件，另比SHA256，不直接把两者当同一哈希。
8. 每次修订另建新版本；不覆盖历史冻结快照，不自动删除未列入新清单的远端文件。

公开仓库不含原PDF。具备合法副本的使用者可运行`python scripts/inventory_source.py <主本.pdf> --alternate <同版副本.pdf> --out <本地报告.json>`。脚本不会证明语义正确；其补页接受状态是本项目这两份特定副本的研究记录，不能套用到任意新PDF。
