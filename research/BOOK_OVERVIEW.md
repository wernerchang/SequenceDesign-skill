# 整书理解：从反馈状态结构到应用指标

## 一句话主旨

通过反馈函数、有限域与图结构构造可控的确定性序列，证明其周期和相关性质，再按真实系统的同步、噪声与实现条件选择适用结构。

## 结构与依赖

1. **对象和表示。** 第一章定义反馈函数、状态图、圈、周期、线性/非线性及非奇异性。它是后续一切参数与算法的语义基础。
2. **线性路线。** 第二章以多项式组织递推、周期、m序列、采样和最短综合。多项式不可约、本原和给定初态的实际周期是不同问题。
3. **非线性路线。** 第三章利用图结构、圈与拼接讨论M序列和非线性综合。局部反馈可逆性只排除暂态，还需要全局单圈条件才能达到2^n周期。
4. **性能路线。** 第四章研究全延迟自相关、互相关、族规模及字母表的折中；第五章分析组合操作对相关和谱的影响。它们要求明确编码、周期、相位与归一化。
5. **系统路线。** 第六章解释序列在测距、导航、多址、加乱、噪声生成和保密中的具体角色。系统需求反过来决定应评价哪一种相关及何种同步模型。
6. **多维推广与参数资料。** 附录将移位和窗口唯一性推广到多维周期阵列；附表承载具体多项式与反馈函数编码，必须先懂其编码和使用约束。

## 跨章核心命题及证明依赖

- 一个有限确定状态系统最终进入圈；寄存器输出周期等于状态圈长，依赖输出窗口能恢复状态，不能推广到任意观测器。
- 反馈对被移出位为异或可分的形式等价于非奇异。这是唯一前驱的局部判据；所有状态是否在同一圈仍是全局问题。
- G_(n−1)欧拉回路对应G_n汉密尔顿圈，以重叠窗口把边覆盖换成状态覆盖，给M序列存在和构造基础。
- 齐次线性反馈的零态固定，m序列的最大非零周期与M序列的全状态周期因此相差一个状态，二者不能混称。
- 采样、组合与换初态都可能改变周期结构；名义长度、候选公周期、最小周期必须分开核算。
- 好的单序列自相关不自动保证一个大族具有好的互相关；Gold等构造需要相应参数条件。
- 周期、非周期和跨符号相关针对不同发送模型；互补序列靠多个相关结果相加抵消，不是每条序列各自零旁瓣。
- 互素子周期下完整相位遍历能够分离某些平均；只作平衡近似时必须保留有限长度修正误差。
- 离散点上的相关乘积不保证连续时间乘积成立；码元形状与插值改变频谱推导。
- 统计分布、相关或长周期性质只支持相应指标，不能单独用来签署数据保密系统的安全性。

这些是研究理解，不是候选三关通过表。复杂互相关定理原书可能只给结论，多维构造也有纲要式证明；研究稿均分别标出原书实际给出的证明强度。

## 术语口径

| 术语 | 本书使用与关键区分 |
|---|---|
| 线性反馈 | F₂上的齐次线性式，仿射常数项不混入此定义 |
| 非退化 | 被指定的最高记忆变量真正影响反馈；一般非线性时不同于非奇异 |
| 非奇异 | 状态映射为置换，无暂态，但可包含多个圈 |
| 移位等价 | 同一周期字的循环移位，同圈初态主要改变相位 |
| m序列 | n级线性寄存器最大非零周期2^n−1的序列 |
| M序列 | 全部2^n状态组成单圈的最大周期序列 |
| 自相关/互相关 | 先声明二元到符号的映射、延迟方向、边界与归一化 |
| 互补 | 多条序列的非周期自相关之和在非零延迟消失 |
| 复码 | 按给定逻辑或时序方式组合子码，性能取决于联合相位遍历 |
| 基块/周期阵列 | 多维窗口及其周期结构，不能仅以总面积判断窗口唯一性 |
